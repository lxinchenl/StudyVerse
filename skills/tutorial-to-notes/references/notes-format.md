# 第10章 数据库保护技术

## 10.3 数据库的完整性

### 四类完整性约束

（先文字简表，再表外代码块——**禁止**在表格里嵌代码块）

| 约束类型 | 核心规则 |
| --- | --- |
| **域完整性** | 字段级：取值范围、格式、默认值、空值 |
| **实体完整性** | 主键唯一且非空 |
| **参照完整性** | 外键为空或等于被参照主键 |
| **用户自定义完整性** | CHECK 或触发器 |

**域完整性 · 示例**

```sql
CREATE TABLE S (
  S# CHAR(9) PRIMARY KEY,
  SSEX CHAR(2) CHECK (SSEX IN ('男', '女'))
);
```

## 段落模板

| 类型 | 格式 |
| --- | --- |
| 摘要 | `> **本章摘要**：…` 放文首 |
| 定义 | `**概念名**：一句话本质` |
| 分类 | 文字简表（两列）+ 表外代码块 |
| 流程 | `流程：Step1 → Step2 → Step3` |
| 图信息 | keep=A：`![说明](images/文件名.png)`；keep=B：文字概括 |
| 重点标黄 | `<mark>核心术语或结论</mark>`（每小节 1~3 处） |
| 例子 | 表外 `**小节名 · 示例**` + 代码块，或 `例：…` 一行 |

## 表格规则（硬性）

1. 每行列数相同；表头下必须有 `| --- | --- |` 分隔行
2. 单元格内**仅纯文本**：禁止 `|`、禁止 ` ``` `、禁止 `<br>`、禁止换行
3. 需要 SQL 示例时：**表写完后**空一行，再写 `**xxx · 示例**` 和独立代码块
4. 代码块：开始行 ` ```sql `、结束行单独 ` ``` `，中间不得插入表格行

## 错误示例（禁止）

- 在表格第三列放 ```sql … ```（会破坏整张表）
- 表格行未闭合就开始代码块
- 单元格写 `CHECK(SSEX IN ('男','女'))` 后又跟 `| **实体完整性** |`（竖线破坏列对齐）

## 压缩原则

- 压缩比约 10:1，要点式条目
- 每个核心概念后跟 `例：` 或表外 SQL 示例
- 资料不足时在文首注明

## 禁止项

- 不用 emoji
- 不编造课件外的规范条文
- 不在表格内嵌套代码块或多行 SQL
